# The Queen — نظام إداري ERP + نقطة بيع POS

نظام متكامل وبسيط لمتجر **The Queen**: تطبيق إداري لكل شيء، ونقطة بيع مرتبطة به مباشرة (نفس قاعدة البيانات، وأي تعديل في الأصناف أو الأسعار يظهر في نقطة البيع فوراً بدون تحديث).

## التثبيت على ويندوز (الطريقة الموصى بها)

ملفات التثبيت في مجلد `dist/`:

| الملف | يُثبّت على | الوظيفة |
|---|---|---|
| `TheQueen-Admin-Setup-1.0.0.exe` | **الجهاز الرئيسي فقط** (جهاز المدير) | النظام الإداري + قاعدة البيانات + الخادم الذي تتصل به أجهزة الكاشير |
| `TheQueen-POS-Setup-1.0.0.exe` | كل جهاز كاشير | نقطة البيع مع الطباعة الحرارية المباشرة |

1. ثبّت **الإدارة** على الجهاز الرئيسي. يعمل تلقائياً مع تشغيل ويندوز ويبقى في الخلفية (أيقونة التاج بجانب الساعة) لخدمة أجهزة الكاشير. إغلاق النافذة لا يوقفه؛ للإيقاف النهائي: أيقونة التاج ← خروج.
2. ثبّت **الكاشير** على أجهزة البيع. عند التشغيل يبحث تلقائياً عن جهاز الإدارة على الشبكة ويتصل به. إن لم يجده: أدخل العنوان الظاهر في الإدارة ← الإعدادات ← المتجر والضريبة ← روابط النظام.
3. في الكاشير اضغط زر **الطابعة** (أعلى الشاشة) واختر الطابعة الحرارية مرة واحدة؛ بعدها تُطبع الإيصالات مباشرة بدون أي نافذة.
4. يمكن تثبيت الكاشير على الجهاز الرئيسي أيضاً (يتصل محلياً).

> ويندوز قد يعرض تحذير SmartScreen لأن الملف غير موقّع رقمياً: اضغط "مزيد من المعلومات" ← "تشغيل على أي حال".
> البيانات محفوظة في `%APPDATA%\The Queen Admin\data` ولا تُحذف عند إلغاء التثبيت.

## التشغيل بدون تثبيت (للتجربة أو على ماك)

المتطلب الوحيد: **Node.js 22.13 أو أحدث** (لا توجد أي مكتبات إضافية).

- **ماك:** انقر مرتين على `start.command`
- **ويندوز:** انقر مرتين على `start.bat`
- أو من الطرفية: `npm start`

ثم افتح:

| التطبيق | الرابط |
|---|---|
| النظام الإداري (ERP) | http://localhost:3000/erp/ |
| نقطة البيع (POS) | http://localhost:3000/pos/ |

لتشغيل نقطة البيع من جهاز آخر (كاشير ثاني، تابلت) على نفس الشبكة: استخدم عنوان IP الظاهر في نافذة التشغيل، مثل `http://192.168.0.113:3000/pos/`.

## الدخول الأول

| المستخدم | الدخول |
|---|---|
| المدير (النظام الإداري) | اسم المستخدم `admin` / كلمة المرور `admin123` — رمز POS: `1234` |
| كاشير 1 (نقطة البيع فقط) | رمز POS: `1111` |

**غيّر كلمات المرور والرموز فوراً** من: الإعدادات ← المستخدمين.

## العملة

- **البيع والحسابات والمخزون كلها بالدينار العراقي** (بدون كسور عشرية، قابلة للتغيير من الإعدادات).
- **كل مورد له عملته**: دينار عراقي أو دولار أمريكي (تُحدد عند إضافة المورد).
- فاتورة شراء من مورد بالدولار: الأسعار بالدولار + سعر الصرف (يُقترح من الإعدادات ويمكن تعديله بالفاتورة). تكلفة الصنف تُحوّل للدينار تلقائياً.
- رصيد مورد الدولار وكشف حسابه يظهران **بالدولار** مع المعادل بالدينار.
- عند سداد مورد الدولار بسعر صرف مختلف عن سعر الشراء، يُسجَّل الفرق تلقائياً في حساب **فروقات أسعار الصرف (5303)**.
- حدّث سعر صرف الدولار من: الإعدادات ← المتجر والضريبة.

## البدء بالعمل (أول يوم)

1. **الإعدادات ← المتجر والضريبة:** بيانات المتجر، الشعار، سعر صرف الدولار.
2. **الأصناف ← استيراد من Excel:** حمّل النموذج، املأه، احفظه من Excel بصيغة **CSV UTF-8** واستورده. الكميات تُسجّل كرصيد افتتاحي.
3. **الموردين والعملاء:** عند الإضافة أدخل **الرصيد السابق** (الديون القديمة). لمورد الدولار يكون الرصيد بالدولار. يمكن إضافة رصيد لاحقاً من صفحة كشف الحساب.
4. **المستخدمين:** أنشئ حساب كاشير لكل موظف برمز سري خاص به.
5. **الإعدادات ← صلاحيات الكاشير:** هل يعدّل السعر؟ هل يعطي خصماً؟ وما الحد الأعلى للخصم %.

## ماذا يحتوي النظام

**النظام الإداري (ERP)**
- لوحة تحكم: مبيعات اليوم والشهر، الأرباح، الصندوق، المخزون، الأصناف المنخفضة.
- المبيعات: فاتورة بيع A4، قائمة الفواتير، المرتجعات، العملاء وكشوف حساباتهم، سندات القبض.
- المشتريات: فاتورة شراء (دينار أو دولار)، **مرتجع مشتريات للمورد**، الموردين، سندات الصرف.
- المخزون: الأصناف، **استيراد/تصدير Excel**، التصنيفات، الجرد والتسوية، حركة الصنف، طباعة ملصقات الباركود.
- فاتورة A4 تطبع **المبلغ كتابةً** (فقط خمسة وستون ألفاً دينار عراقي لا غير).
- المحاسبة: دليل حسابات جاهز، قيود تلقائية لكل عملية، قيود يدوية، المصروفات، كشف حساب.
- التقارير: المبيعات (حسب الصنف/اليوم/التصنيف/المستخدم)، الأرباح والخسائر، الميزانية العمومية، ميزان المراجعة، تقييم المخزون، الورديات. كلها قابلة للطباعة A4.
- الإعدادات: بيانات المتجر والشعار، العملة وسعر الصرف، الضريبة (معطلة افتراضياً)، المستخدمين والصلاحيات، النسخ الاحتياطي.
- **إعدادات الطباعة** مع معاينة مباشرة للفاتورة الحرارية وفاتورة A4 (الشعار، العناوين، الحقول الظاهرة، اللون، الشروط، التذييل، عدد النسخ…).

**نقطة البيع (POS)**
- دخول بالرمز السري، فتح وإغلاق وردية مع مطابقة الصندوق.
- بيع بالباركود أو البحث أو اللمس، تصنيفات، تعديل الكمية والسعر والخصم.
- دفع: نقدي (مع حساب الباقي وأزرار فئات الدينار)، شبكة، مختلط، آجل على حساب عميل.
- طباعة فاتورة حرارية 80mm (أو 58mm) تلقائياً، تعليق الفواتير، مرتجع بمسح باركود الفاتورة.
- اختصارات: `F2` بحث، `F4` تعليق، `F8` العميل، `F9` الدفع.

## الطباعة الحرارية 80mm

1. عرّف الطابعة الحرارية في النظام واجعل حجم الورق 80mm (أو 72mm).
2. في نافذة الطباعة اختر الطابعة، واضبط الهوامش على **بدون (None)**، وألغِ "Headers and footers".
3. للطباعة بدون نافذة في Chrome: شغّل المتصفح بالخيار `--kiosk-printing` وستطبع الفاتورة مباشرة على الطابعة الافتراضية.

## المتجر الإلكتروني (الموقع)

- الموقع مصمم للهاتف أولاً كتطبيق: شريط تنقل سفلي عائم (الرئيسية، الأقسام، السلة، المفضلة، طلباتي)، بحث فوري، سلايدر بنرات، قوائم منبثقة من الأسفل، معرض صور بالسحب والتكبير، ويعمل بشكل كامل على الكمبيوتر أيضاً.
- **مباشر بالكامل**: أي تعديل في سعر أو مخزون أو صنف في النظام يظهر في الموقع خلال ثوانٍ بدون تحديث الصفحة، والطلب الجديد يصل للنظام الإداري فور إرساله، وتغيير حالة الطلب يظهر للزبون مباشرة.
- **النظام الإداري ← المتجر الإلكتروني**:
  - **منتجات الموقع**: الاسم والسعر والمخزون والباركود تُؤخذ تلقائياً من أصناف المتجر. يُضاف للموقع فقط: الصور، الوصف، القسم الرئيسي، القسم الفرعي، البراند (مع تعديل جماعي وفلتر «ناقصة البيانات» وزر «حفظ والتالي» للإدخال السريع).
  - **الأقسام والبراندات**: أقسام رئيسية وفرعية خاصة بالموقع مع صورها، والبراندات مع شعاراتها.
  - **البنرات**: السلايدر الرئيسي، بنر عريض وسط الصفحة، بطاقات ترويجية — لكل بنر صورة كمبيوتر وصورة هاتف، نص وزر، رابط (قسم/براند/منتج/العروض/رابط مخصص)، وجدولة بتاريخ بداية ونهاية.
  - **محتوى الموقع والربط**: الرابط والمفتاح، نصوص الواجهة، واتساب وحسابات التواصل، من نحن والسياسات، أجور التوصيل لكل محافظة، إيقاف/تشغيل الطلبات.
  - **طلبات الموقع**: تصل فوراً مع تنبيه صوتي. المراحل: جديد ← مؤكد ← قيد التوصيل ← تم التسليم (تُصدر فاتورة ويُخصم المخزون تلقائياً) أو إلغاء.
- **لوحة التحكم عن بعد** (`رابط-الموقع/admin`): من الهاتف أو أي جهاز وبنفس حساب المدير في النظام الإداري — تعريف منتجات جديدة وتعديل كل تفاصيلها (الاسم، السعر، الباركود، الوحدة، الصور، الوصف، الأقسام، البراند، النشر)، جرد الكميات، الأقسام والبراندات والبنرات ومحتوى الموقع، ومتابعة الطلبات وتغيير حالتها (التسليم يصدر الفاتورة في النظام). كل تعديل يمر عبر النظام الإداري ويُطبَّق خلال ثوانٍ، وإن كان جهاز المتجر مطفأً تُحفظ التعديلات وتُطبَّق تلقائياً عند تشغيله. سجل كامل يوضح كل تعديل ونتيجته.
- **طلباتي**: الزبون يكتب رقم هاتفه فقط فتظهر كل طلباته الجديدة والسابقة مع حالة كل طلب (بدون عرض العنوان أو البيانات الشخصية).
- الكمية المحجوزة لطلبات مفتوحة لا تُعرض للبيع في الموقع، فلا يُباع نفس القطعة مرتين.

### النشر على السيرفر

```bash
cd /root/thequeen && git pull --ff-only && cd web && docker compose up -d --build
```

مفتاح المزامنة محفوظ في `/root/thequeen/web/.env` على السيرفر فقط (لا يُرفع للمستودع).

## البيانات والنسخ الاحتياطي

- كل البيانات في ملف واحد: `data/queen.db`.
- حمّل نسخة احتياطية من: الإعدادات ← تحميل نسخة احتياطية. للاستعادة: أوقف النظام وضع الملف مكان `data/queen.db`.

## البنية التقنية

```
server.js            الخادم + كل الواجهات البرمجية (API) + التحديث المباشر (SSE)
lib/db.js            قاعدة البيانات SQLite والإعدادات الافتراضية ودليل الحسابات
lib/services.js      المبيعات، المرتجعات، المشتريات، السندات، المخزون، القيود التلقائية
public/shared/       التصميم المشترك + قوالب الطباعة (حراري / A4 / باركود)
public/erp/          النظام الإداري
public/pos/          نقطة البيع
```
